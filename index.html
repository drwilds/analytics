本週數據洞察

✅ 新訪客比例創近期新高,整體流量續揚

  • 總筆數 642 → 677,續增 5.5%,連續兩週成長
  • 新訪客比例 44.4% → 49.9%(+5.5pt),新舊訪客首度接近五五分,漲幅為近期最大
  • 手機使用率維持 8 成以上(80.9%),裝置結構穩定

🔄 backpack 超車奪冠,hydrobarrel2.0 微幅下滑

  • backpack 點擊 136 → 142(+4.4%),擺脫並列局面,成為本週唯一龍頭
  • hydrobarrel2.0 點擊 136 → 126(-7.4%),是九項產品中少數下滑者之一
  • 建議檢視 hydrobarrel2.0 近期渠道與版位是否有變化

🚀 smallbag、rider 量質雙升,成長最猛

  • smallbag 點擊 75 → 106(+41.3%),停留同步大增 13.0 → 17.5 秒(+34.6%)
  • rider 點擊 33 → 53(+60.6%),為全站成長幅度最高的產品,但停留下滑 17.4%值得留意
  • 建議檢視 smallbag 頁面/渠道優化經驗是否可複製到 rider

⚠️ lighttravel 停留大幅下滑,量增質降

  • 停留中位數從 30.0 → 15.0 秒,暴跌 50.0%
  • 點擊仍成長 13.9%(36 → 41),形成「量增質降」的警訊組合
  • 建議排查頁面內容或流量來源是否變得較不精準

🌏 海外流量佔比續揚,新加坡、馬來西亞倍增

  • 海外佔比從 10.7% → 13.6%(+2.9pt),連續兩週提升
  • 香港持續海外第一(24 → 32);新加坡(4 → 12)、馬來西亞(2 → 6)雙雙成長三倍;英國首度進榜(0 → 3)
  • 建議檢視是否有特定活動、廣告或社群貼文帶動這些市場的成長

📊 Instagram、YouTube 帶量強升,直接輸入流量走弱

  • Instagram 17 → 52,暴增 205.9%;YouTube 1 → 5(基期低但漲幅達 400%)
  • 直接輸入網址流量 114 → 85,下滑 25.4%
  • 站內導流(dr-wilds)穩健成長 203 → 220(+8.4%)
