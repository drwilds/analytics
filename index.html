本週數據洞察

⚠️ 整體流量週減37.9%,為近期最大單週跌幅

  • 總筆數 646 → 401,週減37.9%,遠超上週4.6%的降幅
  • 每日趨勢同步走弱(週一127→58,週間各日皆同步下滑),非單日事件所致
  • 手機使用率同步下滑至78.3%(-3.9pt),裝置結構亦受影響

📉 outdoor 由上週最大亮點急轉本週最大重挫

  • outdoor 點擊 78 → 21,暴跌73.1%,為本週跌幅最深產品
  • 停留同步 15.0 → 12.0 秒(-20.0%),量質雙降,與上週「量質雙升」完全反轉
  • 建議優先排查渠道投放、頁面版位或素材是否有重大異動

📊 accessories 點擊腰斩逾六成,惟停留秒數逆勢微升

  • accessories 點擊 33 → 12,跌幅63.6%,為本週次深跌幅
  • 停留秒數 11.0 → 11.5 秒(+4.5%),顯示留存訪客體驗未惡化,問題偏向導流端
  • 建議優先檢視流量來源結構,而非調整頁面內容

🏆 hydrobarrel2.0 點擊持平意外登頂,惟停留大跌26.7%

  • hydrobarrel2.0 點擊 94 → 94,週增率0.0%,因大盤普跌而相對抗跌登頂
  • 停留秒數 15.0 → 11.0 秒(-26.7%),為本週停留跌幅最大產品之一,量穩質降需留意
  • 其新訪客比例僅38.3%,在主力產品中偏低,建議評估訪客結構變化

📱 社群渠道(FB/IG)流量結構性坍縮,連續兩週未見止跌

  • Facebook 27 → 9(-66.7%),Instagram 31 → 9(-71.0%),延續上週已下滑三成以上的趨勢再度腰斬
  • Google自然搜尋、直接輸入、站內導流(dr-wilds)同步下滑,但降幅皆小於社群渠道
  • 站內導流(dr-wilds)相對抗跌,占比由30.5%回升至36.4%,成為大盤下滑中相對穩定的渠道

🌏 海外流量佔比腰斩,香港驟降75%成主要拖累

  • 海外佔比 12.8% → 7.5%(-5.4pt),香港由24 → 6(-75.0%),為海外流失主因
  • 越南、馬來西亞等上週有量的市場本週未進榜或大幅縮減
  • 南韓(0→3)、荷蘭(1→2)小幅補位,惟量體過小尚不足以抵銷香港流失
