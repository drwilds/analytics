本週數據洞察

📊 整體流量小幅回落-6.0%,新訪客比例同步下滑3.4pt

  • 總筆數 502 → 472,週減6.0%,結束上週的大幅反彈,但仍處於近期相對高位
  • 新訪客比例 46.4% → 43.0%(-3.4pt)同步下滑,顯示本週流量略微偏向熟客回訪堆疊
  • 建議觀察下週是否持續回落,若連續兩週下滑則需排查流量來源是否有結構性變化

🏆 backpack連續第二週蟬聯冠軍,但成長動能轉為持平

  • backpack 點擊 117 → 118(+0.9%),連續兩週穩居第一;停留秒數中位數 14.0 → 12.0 秒(-14.3%)小幅走弱
  • 新訪客比例44.9%,居全產品中段,顯示新客與熟客貢獻較為均衡,不同於上週的新客強力導流
  • 建議確認上週帶動成長的渠道或素材本週是否已降溫,評估是否需要補充新曝光以維持動能

⚠️ vest重挫48.6%居跌幅之冠,nomad跌幅更深達52.2%

  • vest 點擊 35 → 18(-48.6%),停留秒數中位數 20.0 → 19.0 秒(-5.0%)同步小跌,為本週前九大產品最大跌幅
  • 未列入圖表的nomad跌幅更為劇烈,點擊 23 → 11(-52.2%),兩者皆為單週急速下滑,波動幅度值得留意
  • 建議排查這兩款產品近期曝光渠道、素材或頁面是否有異動,評估是否為短期波動或流量流失

🚀 DDAY逆勢大漲25.0%,點擊與停留同步成長

  • DDAY 點擊 60 → 75(+25.0%),為本週前九大產品最大漲幅;停留秒數中位數 10.0 → 12.0 秒(+20.0%)同步提升,量質雙升
  • 在整體流量下滑6.0%的背景下逆勢成長,顯示該產品本週獲得的流量品質較高,非單純灌量
  • 建議確認帶動DDAY成長的渠道或素材,評估是否值得加碼延續此波動能

🔀 直接輸入暴增57.4%,站內導流與社群三渠道全面下滑

  • 直接輸入 68 → 107(+57.4%)為本週渠道最大漲幅;站內導流(dr-wilds) 178 → 134(-24.7%)則是最大跌幅,Google自然搜尋199 → 191(-4.0%)相對穩定
  • 社群三渠道同步走弱:Facebook 10 → 4(-60.0%)、YouTube 8 → 3(-62.5%)、Instagram 22 → 18(-18.2%),與站內導流下滑同時發生,恐非巧合
  • 建議排查站內首頁導流動線或社群曝光本週是否有調整,同時留意直接輸入暴增是否為回購熟客或口碑擴散所致

🌏 海外流量佔比微升至7.0%,新加坡、南韓單週暴增400%

  • 海外佔比 6.0% → 7.0%(+1.0pt);香港 6 → 9(+50.0%)續增並持續居首,新加坡、南韓皆由1 → 5(+400%)成長最猛
  • 日本 5 → 3(-40.0%)、越南 4 → 1(-75.0%)明顯降溫,上週客源西班牙、汶萊、墨西哥、德國本週全數掛零,改由法國、印度各2筆首度進榜
  • 建議確認新加坡、南韓本週是否有新增廣告投放或轉發擴散,因基期低、單週波動大,暫不宜視為長期趨勢轉變
