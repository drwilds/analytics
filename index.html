上週數據洞察

⚠️ 整體流量週減4.6%,結束連續兩週成長

  • 總筆數 677 → 646,週減4.6%,終止此前連續兩週的成長趨勢
  • 新訪客比例同步下滑,49.9% → 48.3%(-1.6pt)
  • 手機使用率則逆勢走升至 82.2%(+1.3pt),裝置結構未受影響

🚀 outdoor 量質雙升,為上週最大亮點

  • outdoor 點擊 51 → 78(+52.9%),為全站成長最猛的產品
  • 停留同步 11.0 → 15.0 秒(+36.4%),量質同步提升,非單純灌量
  • 建議拆解其流量來源與素材變化,評估能否複製到其他產品頁

📉 hydrobarrel2.0、accessories 點擊明顯下滑

  • hydrobarrel2.0 點擊 126 → 94(-25.4%),為次熱門產品中跌幅最大者
  • accessories 點擊 49 → 33(-32.7%),停留同步 13.0 → 11.0 秒(-15.4%),量質雙降
  • 建議優先排查兩者近期渠道、版位或素材是否有異動

📊 社群渠道(FB/IG/YT)全面走弱,搜尋與直接流量回升

  • Facebook 42 → 27(-35.7%),Instagram 52 → 31(-40.4%),YouTube 5 → 2(基期低,-60%)
  • Google自然搜尋 247 → 267(+8.1%),直接輸入網址 85 → 109(+28.2%),兩者部分抵銷社群流失
  • 站內導流(dr-wilds)微幅下滑 220 → 197(-10.5%)

🌏 海外流量佔比下滑,香港降溫、澳洲越南新進榜

  • 海外佔比從 13.6% → 12.5%(-1.1pt)
  • 香港仍居海外第一但降溫(32 → 24,-25%);馬來西亞、澳門跌出 Top 8
  • 澳洲(0 → 8)、越南(2 → 8)首度/大幅進榜,值得留意成長來源

✅ backpack 連兩週蟬聯冠軍,量質同步向上

  • backpack 點擊 142 → 148(+4.2%),連續第二週穩坐點擊榜首
  • 停留同步 11.0 → 12.5 秒(+13.6%),量質同步成長
  • 在整體流量下滑的背景下,backpack 表現相對抗跌
